The Engineer's Manual

How the Analytical Engine works, and how to punch a deck for it. Printed by the Engine from {{CARDS}} cards.

The Store and the Mill

Babbage built the Engine in two halves. The Store is a rack of 1,000 columns, each a stack of fifty figure wheels holding one signed number. The Mill does the arithmetic. It has two ingress axes that receive numbers from the Store, an egress axis for the result and a primed egress axis that keeps the remainder of a division.

When the Mill finishes it may set the run-up lever. A result that changes sign from its first operand sets it, as does an overflow past fifty digits or a division by zero. The lever is the Engine's only means of making a decision.

The cards

The Engine is driven by a chain of Jacquard cards laced together and read one at a time.

N017 12345Number card. Set column 17 to 12345.
+ - × ÷Operation card. Choose what the Mill does next.
L017Variable card. Carry column 17 to the next ingress axis. The second axis to fill starts the Mill.
Z017The same, and clear the column.
S017Store the egress axis in column 17. S017' stores the remainder.
PPrint the egress axis.
CF+3Combinatorial card. Skip forward three cards. CB turns the chain back.
CB?14Turn back fourteen cards if the run-up lever is set.
A set typeAttendant card. Print each number as a type sort.
HHalt.

Lines beginning with a full stop are the operator's notes, and the reader passes over them.

The number cards fill columns 1 and 2, and the operation card sets the Mill to add. The two variable cards bring both columns to the ingress axes, and the second sets the Mill turning. A second later 3680 stands on the egress axis, where S003 keeps it and P prints it.

How these pages are printed

The punch reads a manuscript of HTML and turns each character into a three-digit sort. Sixteen sorts fill a column, the first character in the lowest place. Column 0 holds 1,000 and column 1 holds 0. Then for every column of text the punch repeats these fourteen cards, shown here for column 10.

÷  L010  L000  S010  S002'
+  L002  L001  P
-  L001  L010  S003
CB?14

Dividing the column by 1,000 leaves the next character as the remainder, which goes to column 2, and returns the rest to the column. Adding 0 to it brings the character to the egress axis for the printer. Subtracting the column from 0 gives a negative result while characters remain, so the lever is set and the chain turns back to the division. Once the column reads zero the lever stays clear and the chain runs on to the next column.

Punching a deck

  1. Number your columns from 0 to 999. Each holds fifty digits and a sign.
  2. When turning the chain, count from the card after the combinatorial card. CB?14 closing a loop of fourteen cards returns to its first card.
  3. To print text, begin with A set type. The type case holds sorts 1 to 999.
  4. Budget your steam. Each addition or subtraction costs a second, and each multiplication or division a minute.

To change these pages, edit manuscript.html or manual.html and run node tools/punch.mjs. The punch refuses to write a deck unless the Engine prints its manuscript exactly.
